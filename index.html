Sobre o HTML

O HTML é a linguagem de marcação que define a estrutura básica de um site, usando tags para organizar títulos, textos, imagens e links no navegador como o esqueleto de uma página web.

regras da prova

html

Usar apenas os conhecimentos de html adquiridos nas aulas do Thiago se não fica a suspeita do uso de IA.

css

No css com o thiago aprendemos a usar apenas o display do tipo flex (se usar outro na prova zera por suspeita do uso de IA) e deveremos usar apenas os conhecimentos adquiridos nas aulas de html-css.

sem internet

A prova que faremos sera sem o uso da internet (com internet desligada se não zera), para garantir que os alunos não consultem e nem colem de IA.
